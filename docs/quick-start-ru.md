# Talorys: установка и настройка с нуля (простыми словами)

Эта инструкция — для тех, кто не занимается программированием. Она проведёт тебя от пустого места до личного AI-ассистента, который живёт в твоём облаке, отвечает в браузере и в Telegram, ищет в интернете и помнит то, что ты ему скажешь.

> 🇬🇧 Та же инструкция на английском: [docs/quick-start.md](quick-start.md).

Никаких серверов покупать не нужно. Всё работает на бесплатном тарифе Cloudflare.

---

## Что получится в итоге

- **Личный ассистент** на своём адресе вида `https://твоё-имя.pages.dev` — заходишь с пароля и общаешься.
- Он **помнит** факты о тебе, ведёт **задачи, заметки и проекты**, умеет **напоминать** по расписанию и выполнять **рутинные поручения**.
- Общаться можно **в браузере** и **в Telegram** — где удобнее.
- По умолчанию он работает на бесплатной модели Cloudflare, но можно подключить **любую свою модель** (OpenRouter, ChatGPT и др.) — станет заметно умнее.
- Может **читать страницы в интернете** и **искать в интернете** (по желанию — через сервис Tavily, поиск становится лучше).

---

## Шаг 0. Что нужно подготовить (10 минут)

1. **Браузер** — любой современный.
2. **Аккаунт Cloudflare** (бесплатный). Если его нет: зайди на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up), нажми **Sign up**, укажи e-mail и пароль. Банковская карта не требуется.
3. **Установить Node.js** (это такая программа, через которую запускается установщик Talorys):
   - зайди на [nodejs.org](https://nodejs.org),
   - скачай версию с пометкой **LTS** (рекомендуемую),
   - установи как обычную программу: дальше-дальше-готово.
4. **Установить Git** (программа для скачивания кода):
   - зайди на [git-scm.com/downloads](https://git-scm.com/downloads),
   - скачай для своей системы, установи (все галочки по умолчанию — нормально).

Проверка, что всё установилось: нажми **Win+R**, набери `cmd`, Enter. В чёрном окне набери `node -v` и Enter — должна появиться версия (например `v22.14.0`). Потом набери `git --version` — тоже версия. Если обе команды показали версии — готово, идём дальше.

## Шаг 1. Скачать и установить Talorys (10–15 минут)

1. Открой то же чёрное окно (**Win+R** → `cmd` → Enter).
2. Перейди туда, где хочешь хранить программу, например:
   ```
   cd C:\projects
   ```
   (создать папку, если её нет: `mkdir C:\projects`, затем снова `cd C:\projects`)
3. Скачай Talorys:
   ```
   git clone https://github.com/wrinfotel/talorys.git
   cd talorys
   ```
4. Скачай внутренние компоненты (займёт пару минут):
   ```
   npm install
   ```
5. Собери программу:
   ```
   npm run build
   ```
6. Запусти установщик:
   ```
   node packages\create-talorys\dist\cli.js install
   ```
7. Установщик задаст несколько вопросов и попросит войти в Cloudflare:
   - **Login to Cloudflare** — откроется браузер, войди в свой аккаунт Cloudflare и нажми **Allow**. Это одноразовая авторизация, Talorys получит доступ именно к твоему аккаунту.
   - **Agent name** — как будет называться твой ассистент (например, `Талор`). Можно просто нажать Enter.
   - **Enable semantic recall** — «умный поиск по памяти». На бесплатном тарифе можно включить; если не уверен — Enter (нет). Потом можно включить в настройках.
   - **Owner password** — придумай **пароль владельца**. Это единственный пароль для входа в твоего ассистента. Запиши его в надёжное место! Восстановить его нельзя — только сбросить командой `node packages\create-talorys\dist\cli.js reset-password`.
8. Установщик сам создаст всё в твоём Cloudflare и в конце покажет **URL** — твой личный адрес вида `https://talorys-xxxxx-web.pages.dev`. Открой его, введи пароль владельца — ты внутри!

> ⚠️ Важно: вся установка целиком живёт в **твоём** аккаунте Cloudflare. Никакие данные не уходят разработчикам.

## Шаг 2. Сделать ассистента умнее: своя модель (5 минут)

По умолчанию ассистент работает на бесплатной модели Cloudflare (GLM). Она хороша для старта, но ты можешь подключить любую модель через **OpenRouter** — это сервис-посредник, дающий доступ к сотням моделей (в том числе платным и бесплатным) по одному ключу.

1. Зарегистрируйся на [openrouter.ai](https://openrouter.ai) (можно через Google-аккаунт).
2. Зайди в раздел **Keys** (ключи): [openrouter.ai/keys](https://openrouter.ai/keys) → **Create Key** → придумай имя (например, `talorys`) → **Create**.
3. Скопируй показанный ключ (начинается с `sk-or-…`). Показывается он один раз!
   - На бесплатных моделях платить не нужно. Для платных пополните баланс в разделе **Credits**.
4. В своём Talorys: **Settings → AI → Provider**:
   - выбери **Custom (OpenAI-compatible)**;
   - **Base URL**: `https://openrouter.ai/api/v1`
   - **Model**: имя модели, например `openai/gpt-4o-mini` или `anthropic/claude-3.5-haiku` (список — на [openrouter.ai/models](https://openrouter.ai/models));
   - **API key**: вставь свой ключ;
   - нажми **Test** — если появилось зелёное подтверждение, жми **Save**.
5. Готово — теперь ассистент думает выбранной моделью. Кнопка **Disconnect** вернёт бесплатную модель Cloudflare в любой момент.

> 🔒 Ключ хранится в зашифрованном виде внутри твоего ассистента и никуда не отправляется (кроме самого OpenRouter при запросах).

## Шаг 3. Подключить Telegram-бота (10 минут)

1. В Telegram найди официального бота **@BotFather** и напиши ему `/newbot`.
2. Он спросит имя бота — придумай любое (например, `Мой личный ассистент`).
3. Потом спросит **username** — он должен заканчиваться на `bot`, например `my_personal_agent_bot`.
4. BotFather пришлёт **токен** — строку вида `1234567890:AAf4h2m8_…`. Скопируй её целиком. Это «логин и пароль» твоего бота в одном флаконе — никому не показывай.
5. В своём Talorys: **Settings → Integrations → Telegram**:
   - вставь токен в поле **Token**;
   - **Webhook base URL** уже заполнен адресом твоего Talorys — не меняй;
   - нажми **Connect**.
6. Появится **код привязки** (8 символов, действует 15 минут). Открой в Telegram своего нового бота и отправь ему:
   ```
   /start КОД
   ```
   (вместо `КОД` — твой код, например `/start AB12CD34`).
7. Бот ответит, что привязан. Теперь можно писать ему как обычному собеседнику — он отвечает тем же ассистентом, что и в браузере: с памятью, задачами и инструментами.
8. Полезные команды в боте: `/new` — начать новую беседу, `/help` — справка.

**Уведомления в Telegram:** в той же карточке включи переключатель **Deliver notifications here** — и все напоминания и результаты автоматизаций будут приходить тебе в чат.

> 🔒 Бот привязывается только к одному твоему чату. Сообщения от чужих людей он молча игнорирует. Токен хранится зашифрованным.

## Шаг 4 (по желанию). Улучшить поиск в интернете через Tavily

Ассистент и так умеет читать страницы (`web_fetch`) и искать в интернете (`web_search` — встроенный вариант без регистрации). Но если хочется более «умного» поиска:

1. Зарегистрируйся на [app.tavily.com](https://app.tavily.com) (есть бесплатный тариф: 1000 поисков в месяц).
2. Скопируй свой API-ключ (начинается с `tvly-…`).
3. В своём Talorys: **Settings → Integrations → Web search** → вставь ключ → **Save**.
4. Бейдж сменится на **Tavily**. Если сервис Tavily недоступен или ключ перестанет действовать — ассистент автоматически вернётся к встроенному поиску, ничего не сломается.

## Шаг 5. Проверь, что всё работает

Напиши ассистенту (в браузере или в Telegram):

- «запомни, что мой любимый язык программирования — Python» → потом спроси «какой у меня любимый язык?»;
- «добавь задачу: полить цветы завтра в 9 утра» → в назначенное время придёт напоминание (и в Telegram, если включил уведомления);
- «найди в интернете, что нового в Claude» → ассистент поищет и перескажет;
- «прочитай https://example.com и скажи, о чём страница».

## Как обновлять Talorys, когда выходит новая версия

Открой чёрное окно, перейди в папку Talorys и выполни:

```
git pull
npm install
npm run build
node packages\create-talorys\dist\cli.js update --dir "C:\путь\к\папке\установки"
```

Вместо `C:\путь\к\папке\установки` подставь ту папку, куда установщик всё развернул при первой установке — в ней лежит файл `talorys.json` (путь был показан установщиком в конце установки). Все данные, настройки и ключи при обновлении сохраняются.

> 💡 После обновления подожди 1–2 минуты: часть системы перезапускается с небольшой задержкой, и новые пункты настроек могут появиться не мгновенно.

## Частые вопросы

**Забыл пароль владельца.** В чёрном окне, в папке Talorys: `node packages\create-talorys\dist\cli.js reset-password --dir "<папка установки>"` — пароль можно задать заново (данные не теряются, но активные сессии слетят).

**Ассистент пишет, что не может в интернет.** Проверь, что в Settings → AI указана модель (по умолчанию Cloudflare — она работает), а в Integrations включён поиск. Ассистент не может: логиниться на сайты, отправлять письма и запускать программы — это сделано специально.

**Telegram-бот молчит.** Проверь, что ты пишешь именно своему боту, чат привязан (код `/start КОД`), и что после последнего обновления прошло 1–2 минуты.

**Сколько это стоит?** Бесплатный тариф Cloudflare покрывает личное использование. OpenRouter и Tavily имеют бесплатные квоты; платные модели — только если сам пополнишь баланс.

**Кто-то получил мои ключи?** Все ключи (модель, Telegram, Tavily) хранятся зашифрованными внутри твоего ассистента и никогда не показываются в интерфейсе повторно. Если ключ всё же засветился — отзови его у сервиса (OpenRouter/BotFather/Tavily) и вставь новый в тех же настройках.
